### 根病一 · proto 往返腐值 (最深之根 · 以器实证)

`readVarint` 用 `r |= (b & 0x7f) << s` — `<<` 为 **32 位运算**, s ≥ 28 即溢出;
`encodeVarint` 用 `v & 0x7f` — v ≥ 2^31 同腐。而未触之字段亦经 parse→serialize **全量重序列化**
→ **凡 varint ≥ 2^31 (毫秒时间戳 1.7e12 / 大 ID 2^40+) 一经 SP 替换之往返即腐**。

**实证** (dao-proto-rt-test):
```
field1 (ms_ts 1793030000000) 读回 2028637600  ★CORRUPT
field3 (big_id 1099511627776) 读回 256         ★CORRUPT
往返 131B → 126B · 字节不恒等                  ★CORRUPT
```
而后起之 `_pbReadVarint` (模型解锁路) 用 `Math.pow` 反而正确 — **双引擎之裂又现** (同 sp_invert 执一前之局)。
今是否发作取决于真 proto 之 varint 量级; Windsurf 一旦于 chat body 添 ms 时间戳/int64 字段即静默腐请求 — **地雷埋于根**。

**治 (三重)**:
1. `readVarint` 乘法累积 (精确至 2^53) + 返 raw 起点;
2. `parseProto` w=0 存 **raw 原始字节** · `serializeProto` raw 优先直发 — 未触字段**字节级无损** (≥2^53 之雪花 ID 亦直通, 不经值路);
3. `serializeProto` **全序保真** — parse 以 `Symbol.for("dao-proto-ord")` 藏每字段出现全序 (Symbol 于 Object.keys/entries/JSON 皆不可见 · 零扰消费方), serialize 依序直发 · 删者跳 · 增者追末 — 治 oneof (后者胜) / 序敏结构之重排险。

**修后实证**:
```
field1 读回 1793030000000 OK · field3 读回 1099511627776 OK
往返 131B → 131B · 字节恒等 OK
改 SP 后: 时间戳/大 ID/嵌套文 皆保真 OK
```

### 根病三 · 热路 I/O 冗余 (一请七读)

## 二 · 已修之九药 (实 bug · 皆有实证)

### 药① 切经藏 UI 反馈断裂 (extension.js)
`_handleSetCanon` 四处调用 `log()` — 而 extension.js **从未定义 `log`** (只有 `L.info/warn/error`)。
→ 每次面板切经藏: POST 成功后即抛 `ReferenceError` → `canonChanged` 推送与 `forceRefresh` 皆断 → 面板无反馈; catch 内再调 `log()` 二次抛出 → unhandled rejection。
**治**: 四处皆归 `L.info/warn/error("canon", ...)`。

### 药② 回调吞噬 (extension.js `_maybeAnchorAcpEnv`)
`cp.exec(cmd, callback)` / `cp.execFile(cmd, args, callback)` 之第三参乃**函数**(回调), 旧码误作 opts → 返 `{env}` 覆写 `arguments[1/2]` → **回调被吞 → 调用方永挂**。仅中于 devin acp 命令, 然实。
**治**: `if (typeof opts === "function") return;` — 函数即回调, 静默让路。

### 药③ 重启丢模式 (双侧同修 · 根治病)
- extension.js `activate` 以 config `dao.origin.defaultMode`(默 invert) 传 `start()` + `proxySetMode`;
- source.js `start()` 以之覆 `SP_MODE`, 且 handle.`setMode` **落盘** → 用户运行时切换(道⇄官)于窗口重启即被 config 默认**覆没**。
**治**: 双侧「磁盘持久模式优先」— extension.js 新增 `_readPersistedMode()` 先读 vendor `_origin_mode.txt`; source.js `start()` 先 `_loadModeFromDisk()`, 无盘值方用 opts.mode。

### 药④ 隧道自动连接默认关 (安全 · 名实相符)
`server.on("listening")` 后 6s 即 `_brgAutoConnect()`: 自动下载 cloudflared → 起**公网快速隧道**, 暴露**整个反代口** (40 个 `/origin/*` 控制端点 + 数据面) 于公网; 仅 2 端点有 `_handoffGuard`; `/origin/custom_sp`(读写) / `/origin/_quit`(杀进程) / `/origin/mode` / `/origin/tape` 等皆**无鉴权**。
而 Min 版 revproxy 轴已拆 (`_getRevproxy()` 恒 null) → **隧道零收益 · 纯攻击面** · 与「仅隔离替换」之名相悖。
**治**: 自动连接默认关; `DAO_BRIDGE_AUTOCONNECT=1` 显式开; 手动端点 (`POST /origin/revproxy/tunnel`) 保留。道义: 三十六章「国之利器不可以示人」。

### 药⑤ 帧不落盘 (token 不离内存 · 每轮 I/O 损)
`_captureChatFrame` 于**每轮 CHAT_PROTO** 无条件 `writeFileSync` 全帧 (含 **Authorization Bearer + 会话 token** + 全 SP) 至 `~/.codeium/dao-byok/chatframe*.bin/json`; Windows 不 enforce 0o600。而其消费轴 (`_officialChatReplay`) 在 Min 已死 → **凭据落盘 + 每轮 MB 级同步写 · 皆无益**。
**治**: `_persistChatFrame` / `_restoreChatFrame` 默认 no-op (帧仍内存捕·观察面不断); `DAO_FRAME_PERSIST=1` 复旧。道义: 「国之利器不可以示人」。

### 药⑥ 解锁缺省禁 (名实相符)
`_isModelUnlockEnabled()` 文件失时**缺省 true** → 文件偶失即静默启解锁, 与 Min「无模型解锁」之名相悖。
**治**: 缺省 false; 需者显式 `POST /origin/model_unlock {enabled:true}`。

### 药⑦ selftest 永红 (总判修正)
`/origin/selftest` 之 `ok = daoOk && routeOk`; Min 版 `_ea` 恒 null → `routeOk` 恒 false → **自检永报失**。
**治**: 总判唯 `daoOk` (经文载 + 典源在); 外接/解锁两径各自 ok 附陈作观测, 不拖累总判。道义: 三十九章「得一」。

### 药⑧ stop() 不闭 H2 内部服务器 (进程不退之根)
`_bindH2Internal` 所启 `_h2Server` (muxPort+1) 从不闭 → CLI/长活进程 `stop()` 后**进程不退**; 同进程重起则旧 H2 口泄漏。(自检实证: 首轮 30 pass 后进程挂 10s+ 不退; 修后善终 exit 0)
**治**: `stop()` 补 `_h2Server.close()`。

### 药⑨ `/origin/stream` SSE 端点实装 (补断环)
extension.js `DaoSseClient` 订阅 `/origin/stream` (事件 hello/turn/mode/hb/sp) — 而 source.js **无此端点** (合流时失) → 客户端永 404 重连 (1s→30s 退避·永转) · 实时推送之环断 · 面板退化纯轮询。
**治**: 最小 SSE 端点实装 + 三处广播 (mode 变 POST/handle/surface 三路 + canon 变 + inject 变) + 30s hb。实测: hello 达 · mode 广播达 · 面板可实时。道义: 五章「虚而不屈 动而愈出」。

### 附药 (细)
- **`_eaDiag` 无界增长之守**: 每 2000 写检一次, >2MB 截留末 200KB (原: 每请求 2-5 行永不轮转 → GB 级膨胀)。
- **`rpc_classes` 文档补 LOCAL_AUTH** (classifyRPC 六档, 文档原只列五)。
- **死令出列**: `dao.外接api.toggle` 注册 + `tryStartExternalApi/tryStopExternalApi/cmdExternalApiToggle` 三函数 + 自启定时器 + deactivate 调用 — 外接轴 v9.9.374-min 已拆, 令存实亡。
